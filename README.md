# Image Gallery Website

The project especially has been made using images of my village and presents real historical relics then how they has been destroyed by a electric company.

## Project Overview

This project showcases:

- A flex-based layout to display content.
- the use of css for responsive design and styling.

## Features

- **Interactive Layout:**
  - Interactive hover effects for better user engagement.
- **Content Sections:**
  - **h1:** Displays the title of the website.
  - **Main Section:** images and text.
